Overview

Sale Order & Purchase Order Creation From Portal is an Odoo module that enables both customers and vendors to create and manage Sale Orders and Purchase Orders directly from the portal. With this module, authenticated portal users gain self-service capabilities to initiate orders without requiring internal users to intervene. Customers can submit sale orders for products or services, while vendors can place purchase orders seamlessly from their portal accounts.


The module ensures smooth and secure order processing by integrating with Odoo’s native sales and purchasing workflows. Users can view order status, download order documents, and track order progress in real time. This reduces administrative effort, speeds up the order cycle, and enhances user satisfaction through greater autonomy.

Work Flow Of SO & PO Creation From Portal

  • User need to navigate to Website >> My Account here user will see 2 menus Create a Sale Quotation & Create a Purchase RFQ.
  • Further when user click on Create a Sale Quotation will open a form ask certain values & buttons for adding product & generating the sale quotation.
  • User need to select customer & product, on selecting product will set the unit of measure & price automatically and quantity is to be set manually and then clicking on + Add Product add line into the table below.
  • Lastly user need to click on Generate Quotation.
  • Here for any reason if user has not selected the customer will show a alert message.
  • On clicking Generate Quotation will create a quotation showing a success page with button Access Sale Order to redirect to created sale quotation.
  • Clicking Access Sale Order will open a created sale quotation.
  • User can also access the created sale quotation from portal My Account having menu Quotation to Review.
  • If for any case user don't find name in customer field in sale quotation search then user can select + Add New Customer option.
  • + Add New Customer option selection will open a popup asking details.
  • With the details field user need to click Create Customer button & i will create customer with entered details showing a success message.
  • Similarly when user will click on Create a Purchase RFQ will again open a form asking certain values.
  • Similarly like sale quotation when user will select customer, product & click on + Add Product will add a line into table.
  • Clicking on Generate Purchase RFQ will create a purchase RFQ record showing a success page with button Access Purchase Order.
  • Clicking on Access Purchase Order will open a purchase order.
  • User can also access the purchase rfq created from the portal My Account having menu Request For Quotation.
  • Similarly if for any case user don't find name in customer field search in purchase rfq then user can select + Add New Customer option.
  • + Add New Customer option selection will open a popup asking details.
  • With the details field user need to click Create Customer button & i will create customer with entered details showing a success message.
