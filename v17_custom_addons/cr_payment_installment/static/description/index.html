Sales & Invoice Payment Installments

Please send an email at support@creyox.com to know more about this application.


Features

  • User Makes Payment through Installments.
  • Automatically Send Installments Remainder to Customer.
  • Customer Can Pay Different Down Payment.
  • Customer Can Select Tenure Plan for Installments.
  • User can do partial payment of installment.
  • Set Tenure Plan for Installments.
  • User Can Print Installments Report in Sale & Invoice.
  • Easy to use.

Enable Installments

  • Enable "installment on Sale" feature from the user group.
  • Settings => Users => installment on Sale

  • Create Sale order and select product in order line.

Installment In Sale

  • User can fill "Tenure(month)" and "Installment Payment Date" manully.
  • Installment amount automatically calculate based on Tenure(month).
  • Here we can calculate "Installment Amount" and also make down payment.

Create Installment Lines

  • When you will confim sale order installments line will create based on tenure(month).

Installment In Invoice

  • When you create invoice from sale order it will automatically get installments line from sale order.

  • When you will confirm invoice you will see "Partial Payment" and "Pay" button.

Partial Payment

  • User can make partial payment by click on "Partial Payment" button.

Compute Installment

  • After making partial payment you can calculate rest of installment payment.
  • You can recalculate installment by click on "Compute Installment" button.

Pay Installment

  • User can make installment payment by click on "Pay" button.

Installment Remainder

  • Customer will get email automatically day before installment date.

Installment Reports

  • User can print sale installment report within the sale app.

  • User can print sale installment report within the invoice app.
